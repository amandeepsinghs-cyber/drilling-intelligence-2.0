# Design System

Source of truth for tokens: `frontend/src/design/tokens.ts` (mirrors SDD §12.3).

- **Direction:** mission control, not sci-fi.
- **Colour:** graphite surfaces, one accent `#22D3EE`, semantic `ok #34D399 / warn #F59E0B / risk #EF4444` only for real states.
- **Type:** Inter/IBM Plex Sans UI; JetBrains Mono tabular numerals; KPI 56 px.
- **Motion:** 180 ms ease-out on state change only; one alert chime ≤ 400 ms.
- **Modes:** board (4 tracks, big KPIs) / engineer (full suite). **Themes:** dark / light (projector fallback).
- **Plotly template:** transparent paper, `#1E2A36` gridlines, mono tick labels, shared depth axis reversed.
