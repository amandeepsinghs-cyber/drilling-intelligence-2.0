# ADR-007: Optional R3F 3D offset-well view

- **Status:** Accepted (2026-09-25)
- **Context:** Drilling Intelligence 2.0 board demo (see SDD).
- **Decision:** Owner approved an optional 3D view (toggle) in addition to the 2.5D schematic; kept off by default in board mode to avoid gimmickry.
- **Consequences:** Documented in SDD; revisit only via change control (SDD §19).
